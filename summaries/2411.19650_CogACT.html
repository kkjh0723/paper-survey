CogACT: A Foundational Vision-Language-Action Model for Synergizing Cognition and Action in Robotic Manipulation

Qixiu Li, Yaobo Liang, Zeyu Wang 외 15인 · Microsoft Research · Tsinghua University

arXiv abstract PDF 프로젝트 페이지 GitHub arXiv:2411.19650
VLA Diffusion Action DiT Adaptive Ensemble Foundation Model

제출: 2024년 11월 29일 · 백본 DINOv2+SigLIP + LLaMA-2 7B + DiT-L(300M) · Open X-Embodiment 25 데이터셋

한 줄 요약 (TL;DR)

기존 VLA가 action 토큰을 quantize해 VLM 헤드로 붙이는 방식을 취하다 성공률이 낮아지는 문제를, cognition(VLM)과 action(전용 DiT 헤드)을 구조적으로 분리·시너지시켜 해결. LLaMA-2 7B + DINOv2/SigLIP 위에 Diffusion Transformer 300M action head를 얹고 Adaptive Action Ensemble(AAE)로 시계열 예측을 앙상블. SIMPLER Google Robot에서 74.8%(OpenVLA 34.3%, RT-2-X 55B 46.3%), 실 Realman에서 71.2%(OpenVLA 12.1%)로 SOTA. DiT 사이즈 13M→308M로 near-linear 스케일링 관찰.

1배경 · 문제의식

OpenVLA·RT-2 계열은 VLM을 그대로 재활용하되 action을 discrete 토큰으로 양자화해 언어 토큰과 같은 자기회귀 헤드로 뱉는다. 이는 언어와 행동을 억지로 같은 표현 공간에 밀어넣어 표현 mismatch와 성공률 저하를 낳는다. 저자들은 인간의 인지(cognition)와 운동(action) 분리에서 힌트를 얻어 modular 구조—VLM은 상황 이해에, 별도의 diffusion transformer는 연속 궤적 생성에 전념—로 재설계할 것을 제안한다.

2핵심 Contribution

  • Componentized VLA 아키텍처 — 비전(DINOv2+SigLIP), 언어(LLaMA-2 7B), 행동(전용 DiT) 3-모듈. VLM 출력은 조건으로만 쓰고 action은 별도 diffusion head가 담당.
  • Diffusion Action Transformer — DiT-S/B/L(13M/89M/308M)의 favorable scaling을 검증하고 log-linear 성능 향상 확인. 예측 horizon 15 step이 최적.
  • Adaptive Action Ensemble (AAE) — 과거 예측과 현재 예측의 cosine 유사도로 가중해 부드러운 실행 궤적을 생성. temporal ensemble(58.9%)·action chunking(50.7%)을 62.5%로 상회.

3Method

구조: Cognition · Action 분리

VLM(Prismatic-7B 구조: DINOv2+SigLIP 비전 이중 인코더 + LLaMA-2 7B)이 이미지·언어를 처리해 마지막 hidden state의 특별 토큰을 cognition feature로 뽑는다. 이 feature가 DiT-L(300M) action head에 AdaLN-Zero 방식으로 주입되어 다음 15-step 연속 action chunk를 생성한다. 학습 시 표준 DDPM(1000-step 스케줄), 추론 시 DDIM 30-step.

Adaptive Action Ensemble (AAE)

매 시점 t에서 최근 여러 chunk 예측을 유지하고, 현 예측 ât와 과거 예측 ât−k의 cosine 유사도 sk를 softmax 가중치로 사용: wk ∝ exp(sk/τ). 유사할수록 가중이 커져 일관된 궤적을 자기강화하고 outlier를 배제. temporal ensemble의 고정 지수 감쇠보다 상황 적응적.

5Ablation (주요 발견)

  • Action head 종류: MLP·discrete token head 대비 DiT가 큰 폭 우위. 동일 파라미터에서 DiT가 최고.
  • DiT 사이즈 스케일링: 13M(S) → 89M(B) → 308M(L)로 log 스케일 근사 선형 향상. 300M이 성능/비용 최적 sweet spot.
  • 예측 horizon: 0 · 3 · 15 · 31 step 중 15 step 최적. 너무 짧으면 부드럽지 못하고, 너무 길면 오차 누적.
  • Ensemble 방식: Adaptive(AAE) 62.5 > Temporal 58.9 > Action Chunking 50.7. cosine 가중이 상황별 우세 예측을 자동 선택.
