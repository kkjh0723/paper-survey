KineBench: Benchmarking Embodied World Models via IDM-Free Kinematic Grounding

Zeyu Liu, Zhangzhe Zhu, Yang Zhang, Chenyou Fan, Chenjia Bai, Xuelong Li

arXiv abstract PDF HTML arXiv:2607.19876
Embodied World Model IDM-Free Closed-loop Eval ManiSkill3 FoundationPose

제출: 2026년 7월 22일 · ManiSkill3 20 태스크 · 4 progressive suite

한 줄 요약 (TL;DR)

Embodied world model(EWM) closed-loop 평가에서 Inverse Dynamics Model(IDM)에 의존하면 world model 오류인지 IDM 오류인지 attribution 모호성이 남는다. KineBench는 IDM을 제거하고, 생성 비디오에서 YOLOv11 → MoGeV2(뎁스) → FoundationPose 캐스케이드로 프레임별 6D end-effector pose를 직접 뽑아 ManiSkill3에서 실행. execution 성공에 더해 SPARC·Manipulability Index로 궤적 부드러움/기구학 타당성을 채점. Wan 2.2 5B가 basic 56.32%, task transfer 11.90%, LoRA는 57.78%로 full FT보다 사전학습 prior 보존이 유리. 태스크 복잡도별 nonlinear scaling을 실증.

1배경 · 문제의식

EWM은 액션을 조건으로 미래 관측을 생성하고, 그 rollout이 실제 물리적으로 그럴듯해야 한다. closed-loop로 평가하려면 생성 비디오에서 액션을 다시 뽑아 시뮬레이터로 실행해봐야 하는데, 지금까지의 표준 도구인 IDM은 2D 픽셀 → 3D 기구학 매핑이 학습 분포 밖(새 물체·씬)에서 취약해 잘못된 액션을 뱉는다. 결과적으로 WFM이 나쁜지 IDM이 나쁜지 구분할 수 없다. KineBench는 IDM 자체를 없애 이 attribution 문제를 해결한다.

2핵심 Contribution

  • IDM-Free 캐스케이드 파이프라인 — 생성 비디오에서 (i) YOLOv11로 grip mask, (ii) MoGeV2(2단계 파인튜닝)로 metric depth, (iii) FoundationPose의 Render-and-Compare로 6D pose 추출. rigid-body constraint가 물리적 hallucination(그리퍼 소실 등)을 자연스레 검출.
  • 3-종 메트릭 — execution success에 더해 SPARC(Spectral Arc Length)로 궤적 부드러움, Maruyama Manipulability Index로 기구학 타당성을 robot-centric 시점에서 채점.
  • 4-단계 progressive 벤치 — ManiSkill3 20 태스크 위에 (0) basic execution, (1) task transfer, (2) visual OOD, (3) complexity-conditioned scaling.
  • Frontier EWM 대규모 평가 — Wan 2.1(1.3B), Wan 2.2(5B), CogVideoX(2B), LoRA 파인튜닝 변종, 폐쇄 소스 API까지. task-complexity-bounded nonlinear scaling을 실증.

3Method

IDM-Free 6D pose 추출

기존 프레임워크는 픽셀→액션 IDM에 의존하지만, KineBench는 이를 완전히 제거하고 Vision Foundation Model 캐스케이드로 각 프레임의 gripper 6D pose를 직접 추출한다:

  1. YOLOv11 (fine-tuned) — 각 프레임에서 gripper 2D 마스크 추출.
  2. MoGeV2 (2-stage fine-tuned) — 마스크 영역의 metric depth map 생성.
  3. FoundationPose — CAD 모델과의 render-and-compare 반복 정렬로 zero-shot 6D pose tracking. rigid-body 제약이 고주파 noise를 자연 필터링.

추출된 pose 시퀀스를 그대로 ManiSkill3 물리 시뮬레이터에 execution → 진짜 성공 여부를 얻는다.

4-단계 Progressive Suite

  • Suite 0 — Basic Execution: 학습 분포 내 20 태스크로 기본 execution 성공률 측정.
  • Suite 1 — Task Transfer: 새 태스크 조합으로 EWM의 일반화 능력 진단.
  • Suite 2 — Visual OOD: 미지의 시각 자산(물체·조명·배경)으로 견고성 시험.
  • Suite 3 — Complexity Scaling: 태스크 복잡도별 데이터/모델 스케일링 곡선.

"태스크 복잡도로 bounded된 nonlinear scaling" — 단순 태스크는 데이터 추가가 오히려 소용없고, 복잡 태스크에서 데이터 스케일이 결정적.

SPARC / Manipulability 관찰

  • Zero-shot 모델은 SPARC와 success 상관이 강함 → 부드러운 궤적이 곧 성공.
  • Full fine-tuned 모델은 SPARC가 포화되며, 실패는 semantic error가 주 원인.
  • Zero-shot은 Manipulability 위반이 빈번(특이점 근접), Full FT는 상대적으로 잘 지킴.

5Ablation / 관찰

  • IDM 없앤 것의 실효 — 새 물체·씬에서 IDM이 붕괴하는 관측을 제거해 attribution 모호성을 해소. WFM 순위가 IDM 선택에 흔들리지 않는다.
  • LoRA가 Full FT를 이기는 조건 — task transfer에서 명확. 사전학습 prior를 얼마나 보존하느냐가 downstream generalization을 결정.
  • 데이터 스케일링은 태스크 종속 — "무조건 더 많이"가 아니라 태스크 복잡도별 curve를 봐야 함. 단순 태스크는 saturation, 복잡 태스크는 큰 이득.
  • 기구학 메트릭의 상보성 — 성공/실패만 보면 놓치는 "위험한 성공(특이점 근접)"을 Manipulability로 진단 가능.

6핵심 Figure / Table

핵심 메시지 — WFM 평가에서 IDM에 의존하는 관행을 없애야 진짜 세계 모델 품질이 드러난다. 그리고 데이터 스케일링의 결과는 태스크 복잡도로 bounded되어 있어, 데이터 mix를 태스크 스펙트럼에 맞춰 설계해야 한다.
