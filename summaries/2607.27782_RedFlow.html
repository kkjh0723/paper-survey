RedFlow: Redirect Failure into Action-Level Corrections for Flow-matching VLA Policy

Zhengyang Yan, Junhao Li, Fangqi Zhu 외 6인 · arXiv:2607.27782

arXiv abstract PDF arXiv:2607.27782

제출: 2026년 7월 30일 · 벤치 LIBERO 4-suite · 실로봇 3태스크 · on-policy 대비 ~10× 샘플 절약

한 줄 요약 (TL;DR)

Flow-matching VLA를 실패 rollout까지 활용해 offline로 개선하는 프레임워크. 기존 offline RL은 실패 데이터로부터 action-level 교정 신호를 못 뽑아 학습 효율이 낮다. RedFlow는 Context-Aware Corrective Matching으로 유사 컨텍스트의 성공 chunk에서 교정 타깃을 만들고, Adaptive Redirection Objective(attraction+suppression+redirection 3항)로 flow field를 갱신. LIBERO 평균 68.2%(baseline 56.2 · AWR 62.3 · DPO 59.7). 실로봇 clothes-folding 36.0→67.0%. On-policy PPO/GRPO/DDPO를 ~10× 적은 샘플로 매칭.

1배경 · 문제의식

Flow-matching VLA(π0 등)는 강력하지만 배포 시 분포 이동으로 인한 누적 오차가 발생한다. On-policy RL(PPO·GRPO·DDPO)은 rollout이 매우 비싸고, 기존 offline RL(AWR·DPO)은 chunk 전체를 좋음/나쁨으로만 판별해 "이 chunk의 이 부분이 왜 실패인지"라는 action-level 정보를 못 뽑는다. 결과적으로 실패 데이터가 사실상 낭비된다.

2핵심 Contribution

  • Context-Aware Corrective Matching — 실패 chunk의 컨텍스트(정규화 proprio + GRM 진행도)를 HDBSCAN으로 클러스터링, 같은 클러스터의 성공 chunk를 quality-weighted centroid로 묶어 대체 타깃으로 사용.
  • Adaptive Redirection Objective — (a) 성공 chunk를 잡아당기는 quality-weighted attraction, (b) 실패 chunk를 밀어내는 hinge suppression, (c) 복구 가능한 실패는 corrective target으로 redirection. Wasserstein gradient flow 이론으로 "low-quality endpoint에서의 bounded exclusion" 보장.
  • 극단적 샘플 효율 — 1,536 offline 궤적으로 PPO(~13K)·GRPO(~16K)·DDPO(~24K)에 도달. Offline data만으로 on-policy 성능 매칭.

3Method

Flow-matching 백본

조건부 flow-matching 모델이 noise → action chunk 매핑을 학습(정규화된 flow 시간 t를 따라 velocity field vθ). 사전학습은 전문가 데모의 표준 flow-matching regression: LFM = 𝔼‖vθ − (a − ε)‖².

Context-Aware Corrective Matching

각 chunk의 advantage는 smoothed progress estimate + trajectory outcome으로 산출. 컨텍스트 벡터 = (정규화 proprio, GRM-predicted progress). HDBSCAN으로 execution-context cluster를 형성, 클러스터 내 positive chunk의 quality-weighted centroid가 corrective target ã. "복구 가능한 실패"만 이 타깃으로 redirect.

Adaptive Redirection Objective

3항 결합 손실:

  • Attraction (Latt) — 성공 chunk에 대해 velocity field를 quality-weighted로 강화.
  • Suppression (Lsup) — 실패 chunk에 대해 hinge loss로 재생성 확률 억제.
  • Correction (Lcor) — 복구 가능한 실패를 corrective target ã로 pull.

이론적으론 Wasserstein gradient flow 관점에서 low-quality endpoint로부터의 bounded exclusion이 보장됨.
