τ0-VLA: a Hierarchical Robot Foundation Model with World-Model-Guided Test-Time Computation

Xiaowei Cai, Jianlan Luo, Buqing Nie, Xiangyu Yue 외 40여 명 (알파벳순) · Agibot Finch · Shanghai Institute of Innovation · CUHK

프로젝트 페이지 PDF arXiv 번호 미부여
Hierarchical VLA World Model Test-Time Computation Beam Search Long-Horizon

High-level Qwen3.5-9B · Low-level Qwen3.5-2B + MoT action expert · 40,115시간 실세계 데이터

한 줄 요약 (TL;DR)

긴 호라이즌 조작에서 상위 정책(subtask 생성)을 한 번의 forward pass로 끝내지 않고, 월드모델 기반 test-time computation(TTC)으로 여러 후보 subtask를 탐색·검증하는 계층형 로봇 파운데이션 모델. 상위 정책이 후보를 제안(P)하면 월드모델(W)이 실행 후 이미지를 상상하고 가치모델(V)이 진행도를 채점, beam search로 상위 분기만 남겨 깊이 D까지 확장한 뒤 reflect & commit. 40,115시간 데이터로 학습한 하위 VLA가 실행. 장기 태스크 평균 성공률 45%(π0.5 22.5%, GR00T N1.7 2.5%), 분포 이탈(OOD) 다음-subtask 예측 정확도 74%(Plan-Once 50%, Best-of-N 57.5%).

1배경 · 문제의식

방 청소·요리·음료 준비 같은 장기(long-horizon) 조작은 수분~수시간에 걸친 연속적 의사결정을 요구한다. 로봇은 무엇이 끝났고 무엇이 남았는지 추론하고, 중간 결과를 검증하며 국소 실패를 복구해야 한다. 핵심은 "잘못된 subtask 선택은 정밀한 모터 제어로도 되돌릴 수 없다"는 점 — 로봇이 엉뚱한 subtask를 완벽하게 수행할 뿐이다.

대부분의 계층형 VLA는 이 subtask 결정을 매 스텝 단일 forward pass로 내려, 어렵거나 결정적인 선택에 추가 연산을 배분할 메커니즘이 없다. τ0-VLA는 상위 subtask 생성을 연산량으로 확장 가능한 추론(compute-scalable inference) 문제로 재정의한다.

2핵심 Contribution

  • 월드모델 유도 Test-Time Computation — 상위 정책이 필요할 때만 후보 subtask를 탐색. 제안(VLM)→월드모델의 결과 예측→가치모델 채점→beam search→reflect&commit의 파이프라인으로, 추가 연산이 다음-subtask 예측 정확도를 실제로 끌어올림을 실증.
  • 실행 메모리 기반 계층 구조 — 상위 정책이 관찰 정렬 실행 메모리 Mt를 유지하며 언제 추가 연산을 쓸지 스스로 결정. 하위 VLA는 committed subtask를 여러 임바디먼트에서 실행.
  • 대규모 다임바디먼트 파운데이션 — 40,115시간 이질적 실세계 데이터(원격조작·자율수집·UMI)로 멀티모달 공동학습. 장기 이동조작·정밀조작·교차 임바디먼트 일반화를 한 모델로 커버.

3Method

계층 구조 개요

매 논리적 추론 스텝에서 상위 정책 µ가 먼저 subtask z★t를 생성하고, 하위 정책 πθ가 그 subtask를 조건으로 액션 청크를 생성한다. 상위 정책은 결정 맥락 ht = (ℓ, Mt−1, z★t−1, ot)를 구성 — 언어 지시 ℓ, 이전 실행 메모리 Mt−1, 직전 subtask, 현재 관찰 ot. 그리고 (Mt, z★t) = µ(ht)로 메모리를 갱신하고 subtask를 낸다. subtask가 유지되면 실행을 이어가고, 바뀌면 새 subtask 실행을 시작.

상위 정책 (High-Level Policy)

Qwen3.5-9B VLM. 멀티뷰 관찰 + 태스크 지시 + 실행 메모리 + 직전 subtask를 받아, 추론과 함께 갱신된 메모리 Mt와 직접 제안(direct proposal) zdirt를 산출. 여기서 직접 제안에 곧장 commit하거나, 어려운 결정이면 추가 test-time computation을 호출할 수 있다.

월드모델 유도 TTC (핵심)

TTC 경로에서는 각 유지 분기마다 제안 모델을 N번 호출해 N개 후보 subtask를 생성한다. 그 뒤:

  • P (Propose) — VLM이 후보 subtask 제안 (예: "Pick Up Spoon", "Place Cup", "Pick Up Cup").
  • W (World Model) — 분기의 head-camera 이미지 + 후보를 받아 실행 후 종단 head-camera 이미지를 상상(예측).
  • V (Value Model) — 태스크 지시·후보·예측 이미지를 조건으로 후보 품질 점수를 부여(예: 0.95 / 0.50 / 0.95).
  • Beam Search — 누적 점수 기준 상위 B개 분기만 유지하고, 이를 재귀적으로 깊이 D까지 확장.
  • F (Reflect & Commit) — 깊이 D 후, 유지된 분기와 그 예측 결과를 근거로 reflective 모델이 다음 subtask를 최종 확정.
즉 TTC는 "제안 → 상상 → 채점 → 가지치기 → 반성"의 탐색이며, 연산 예산(PFLOPs/sample)을 늘릴수록 subtask 예측 정확도가 단조 증가·포화하는 test-time scaling 곡선을 보인다(그림 5).

하위 정책 (Low-Level Policy)

Qwen3.5-2B VLM 백본 + MoT(Mixture-of-Transformers) action expert. committed subtask, 멀티뷰 관찰 ot, 고유수용 상태 st, 텍스트 제어 메타데이터 η를 조건으로, 노이즈 액션 청크에서 조건부 flow matching으로 액션 청크 at:t+H−1를 생성.

Test-Time Computation의 효과 (다음-subtask 예측 정확도)

OOD Book Organization 설정(초기 배치가 학습에 없음)에서 TTC 74.0% vs Plan Once 50.0% vs Best-of-N 57.5%. 분포 이탈로 단일 예측이 취약해질수록, 월드모델로 미래를 상상하고 가치모델로 채점하는 탐색이 크게 이득.

5주요 관찰 · 분석

  • 계층 + 탐색의 결합이 핵심: 단순히 하위 VLA를 잘 만드는 것(직접 실행 27.5%)만으로는 부족하고, 상위 subtask 결정에 월드모델 유도 탐색을 얹을 때(45.0%) 초장기 태스크에서 급격한 이득.
  • 분포 이탈에서 특히 강함: in-domain보다 OOD에서 TTC의 상대 이득이 크다(74% vs Plan Once 50%). 학습 분포 밖 관찰에서 단일 예측이 흔들릴 때 상상·검증 탐색이 보정.
  • 연산-정확도 트레이드오프가 부드러움: 어려운 결정에만 연산을 더 쓰고 쉬운 결정은 직접 제안으로 처리 — 예산을 선택적으로 배분.
