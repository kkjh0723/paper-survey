Robotic Control via Embodied Chain-of-Thought Reasoning (ECoT)

Michał Zawalski, William Chen, Karl Pertsch, Oier Mees, Chelsea Finn, Sergey Levine · UC Berkeley · Stanford · University of Warsaw

arXiv abstract PDF 프로젝트 페이지 GitHub arXiv:2407.08693
VLA Chain-of-Thought Reasoning OpenVLA Generalization

제출: 2024년 7월 11일 (v1) · 최신 2025년 3월 6일 (v3, CoRL 2024) · 백본 OpenVLA(Llama 2 7B + SigLIP/DinoV2)

한 줄 요약 (TL;DR)

VLA(Vision-Language-Action model, 관측 이미지·언어 지시를 입력받아 로봇 행동 토큰을 출력하는 대형 정책 모델)가 행동을 뱉기 직전에 사람처럼 단계별로 추론(Chain-of-Thought, CoT)하도록 학습시키되, 계획·서브태스크 같은 텍스트 추론뿐 아니라 물체 바운딩 박스와 그리퍼 픽셀 위치 같은 몸에 근거한(embodied) 시각 추론까지 자기회귀(autoregressive)로 생성하게 만든 것. 로봇 데이터를 추가로 모으지 않고 기존 OpenVLA에 이 추론 체인을 학습시키는 것만으로 일반화 태스크 성공률이 +28%p (44%→66% ID, 30%→64% OOD, 여기서 OOD는 out-of-distribution: 학습에 없던 조건) 향상됐다.

1배경 · 문제의식

학습된 로봇 정책의 최대 약점은 학습 분포 밖으로의 일반화 실패다. 최근 VLA(vision-language-action model, 예: OpenVLA·RT-2-X)는 인터넷 사전학습된 비전-언어 모델(VLM)에 로봇 행동 토큰 예측을 붙여 큰 상식·시맨틱 지식을 물려받았지만, 실제로는 관측 → 행동을 곧바로 매핑해 이 지식을 잘 활용하지 못한다.

대형 언어 모델(LLM)에서는 chain-of-thought(CoT, 답을 내기 전 중간 추론 단계를 텍스트로 풀어쓰기)가 복잡 문제 성능을 크게 끌어올렸다. 저자들은 이 아이디어를 로봇 정책에 그대로 옮기면 부족하다고 본다 — 로봇은 순수 언어가 아니라 현재 장면과 자신의 몸 상태에 근거해 사고해야 하기 때문이다. 그래서 계획·서브태스크 같은 언어 CoT에 더해 물체 바운딩 박스·그리퍼 2D 위치·저수준 이동 명령을 함께 생성하도록 강제하는 Embodied CoT(ECoT)를 제안한다.

2핵심 Contribution

  • Embodied Chain-of-Thought 정식화 — VLA에게 행동 예측 이전에 언어 계획(plan)·서브태스크·저수준 움직임뿐 아니라 그리퍼 픽셀 좌표·물체 바운딩 박스까지 자기회귀로 생성시키는 7단계 추론 체인 (task → plan → subtask → move → gripper → objects → action)을 제안.
  • 대규모 자동 주석 파이프라인 — Prismatic-7B(장면 캡셔닝) + Grounding DINO(물체 박스) + OWLv2+SAM+RANSAC(그리퍼 2D 위치) + 로봇 proprioception(저수준 이동 라벨 729가지) + Gemini 1.0(고수준 계획·서브태스크)을 조합해, Bridge V2 데이터셋(60k 원격조종 데모, 2.5M 전이) 전체에 7일 만에 ECoT 주석을 자동 생성.
  • 일반화 성능 대폭 향상 — 새 로봇 데이터 없이 OpenVLA를 ECoT 데이터로 파인튜닝만 해도 총 일반화 성공률 +28%p. 추가 이득: 자연어 개입(intervention)으로 실패를 실시간 교정 가능하고, 각 추론 단계를 그대로 읽어 실패 원인을 해석 가능.

3Method

백본: OpenVLA

OpenVLA는 Prismatic VLM 아키텍처 기반의 오픈소스 VLA로, 비전 인코더로 SigLIP과 DinoV2 특징을 융합하고 언어 백본으로 Llama 2 7B를 쓴다. 로봇 행동(7-DoF: 3차원 위치 변화 + 3차원 회전 변화 + 그리퍼 개폐 1)을 각 축당 256개 bin으로 이산화(action tokenization: 연속 값을 정수 토큰으로 양자화)해 언어 토큰과 동일한 방식으로 예측한다. ECoT는 OpenVLA를 그대로 사용하고, 학습 목표만 "이미지+지시 → 행동 7토큰"에서 "이미지+지시 → ECoT 추론 체인 + 행동 7토큰"으로 바꾼다.

ECoT 추론 체인 — 7단계 구성

왜: 로봇 정책이 "왜 이 행동인가"를 텍스트+공간 좌표로 먼저 뱉게 만들면, 모델이 스킵할 수 없는 grounding 병목이 생겨 상식 지식이 실제 장면과 연결된다. 특히 bounding box·그리퍼 좌표는 "look carefully" 강제, plan·subtask는 "think carefully" 강제 역할.
① TASK
주어진 자연어 지시를 다시 정리 (예: "Put the mushroom in the white cup")
② PLAN
고수준 단계 나열 ("Move to mushroom → pick up → move to cup → place inside")
③ SUBTASK
지금 이 timestep에서 실행할 하위 목표 ("Move to the mushroom")
④ MOVE
저수준 이동 primitive ("move left", "close gripper" 등, 총 729가지 템플릿)
⑤ GRIPPER
로봇 엔드이펙터(그리퍼)의 현재 2D 픽셀 좌표 (x, y)
⑥ OBJECTS
장면 내 물체 이름 + 바운딩 박스 좌표 (x1, y1, x2, y2) 리스트
⑦ ACTION
OpenVLA와 동일한 7-DoF 이산 행동 토큰 7개

①~④는 "언어" CoT, ⑤~⑥은 "embodied" CoT (장면·로봇 상태에 grounding하는 단계). 모든 단계는 자기회귀로 순서대로 하나의 시퀀스에 이어붙여 학습되므로, ⑦(행동)을 예측할 때 모델은 자기 자신이 조금 전 생성한 계획·박스·좌표를 조건으로 삼는다.

자동 주석 파이프라인 (Bridge V2에 확장)

왜: 이 추론 체인을 사람에게 라벨링시키는 건 비현실적. 기존 대형 모델들을 조합해 모든 데모 프레임에 자동으로 주석을 붙일 수 있으면 스케일업이 무료다.
  • 장면 설명: Prismatic-7B VLM으로 초기 프레임 캡션 생성.
  • 물체 박스: Grounding DINO로 텍스트 조건부 탐지 (박스 신뢰도 >0.3, 텍스트 >0.2).
  • 그리퍼 픽셀 좌표: OWLv2로 그리퍼 검출 → SAM으로 마스크 → 로봇 proprioception(관절 상태)의 3D 위치를 RANSAC으로 프로젝션 매트릭스 fit해 2D 매핑.
  • 이동 primitive: proprioception 델타를 729가지 템플릿(예: "move left and down, rotate wrist counterclockwise")으로 매핑.
  • 계획·서브태스크: Gemini 1.0에 지시·장면 설명을 넣어 PLAN·SUBTASK 라벨링.

전 파이프라인이 Bridge V2 60k 데모·2.5M 전이를 7일에 처리해 학습셋 완성.

학습 & 추론 가속

학습은 표준 자기회귀 교차엔트로피 하나로 통일 — 추론 체인 전체(약 350 토큰)를 다음 토큰 예측 손실로 학습. 순수 OpenVLA는 액션 7토큰만 뱉으면 되지만 ECoT는 350토큰을 생성해야 하므로 실시간성에 부담. 두 가지 가속:

  • 5-step freeze: 상위 추론(PLAN까지)은 5 타임스텝마다 한 번만 재예측하고 그 사이엔 재사용. 성공률 72%로 유지하며 속도 +24%.
  • Asynchronous execution: 두 정책 인스턴스를 병렬로 돌려 한쪽이 다음 추론을 미리 만드는 동안 다른 쪽이 행동. 성공률 65%, 속도 +40% (연산 2배 필요).

Transformer는 이미 생성한 토큰을 다시 인코딩하는 비용이 새 토큰 생성보다 훨씬 싸므로, 상위 추론 재사용의 상대 비용이 매우 낮다.

자연어 개입(intervention) 실험

3개 난이도 높은 태스크(mushroom→cup, OOD 물체 잡기, "노란 게 아닌 것" 고르기)에서 실패 중인 정책에 사람이 한 문장 언어 교정을 주었을 때: ECoT는 +48%p 성공률 상승, OpenVLA·RT-2-X는 거의 효과 없음. 이유: ECoT는 PLAN/SUBTASK를 텍스트로 만들기 때문에 사람이 그 텍스트를 직접 덮어쓸 수 있음.

5Ablation (주요 발견)

  • Frozen bounding box variant: 매 스텝 박스를 새로 예측하지 말고 첫 스텝 것을 고정 재사용 → 성공률 60%(약간 감소), 대신 추론 속도 30–50% 빨라짐. 해석·성능·속도 트레이드오프의 스위트스팟.
  • 비전-언어 데이터 co-training: 로봇 학습과 함께 순수 VQA 데이터를 섞어 학습 → 제어 성공률 이득 없음. 사전학습 시맨틱 지식은 이미 백본에 충분히 있고, 로봇 데이터의 embodied grounding이 핵심임을 시사.
  • OXE(Open X-Embodiment) 멀티로봇 데이터 파인튜닝: Bridge V2 단독보다 수렴이 4배 빠름 (20k 스텝이 baseline 80k와 동등). Cross-embodiment 사전학습이 ECoT에도 유효.
  • 추론 단계 중요도: 계획 텍스트만 있는 pure-CoT보다 embodied 단계(bounding box·gripper) 포함이 일관되게 우수 — "look carefully"가 grounding 병목으로 작동한다는 주장의 증거.
