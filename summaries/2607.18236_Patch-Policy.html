Patch Policy: Efficient Embodied Control via Dense Visual Representations

Gaoyue Zhou, Zichen Jeff Cui, Ada Langford, Bowen Tan, Yann LeCun, Lerrel Pinto · New York University

arXiv abstract PDF HTML 프로젝트 페이지 arXiv:2607.18236
Dense ViT Features DINOv2 / WebSSL Block-Causal Attention Frozen Backbone Efficient Policy

제출: 2026년 7월 20일 · 동결 ViT(DINOv2·WebSSL 등) + 정책 트랜스포머만 학습 · 51.55M 파라미터 · 1×L40S 6.5 GPU-hour

한 줄 요약 (TL;DR)

사전학습 ViT의 dense patch 토큰을 global pooling 없이 그대로 정책에 먹이는 경량 조작 정책. 프레임 내부는 양방향, 프레임 간은 causal인 block-causal attention으로 공간 디테일과 시간 인과성을 동시에 확보. 동결 ViT + 작은 정책 트랜스포머만 학습해, global-pooled 표현 대비 +40%, 파인튜닝 OpenVLA-OFT 대비 +18%를 파라미터 0.7%(51.55M vs 7.61B)·지연 10.99ms(vs 61.71ms)로 달성. 실로봇 Cable Insertion 완전삽입 70%(OpenVLA-OFT 30%), Tool Hanging 90%(65%).

1배경 · 문제의식

ViT의 사전학습 dense feature는 강력하지만 로봇 학습에서 저활용돼 왔다. 현재 정책은 둘 중 하나로 치우친다: (1) 각 관찰을 단일 global 토큰(ResNet 풀링·ViT CLS)으로 압축 → 세밀한 공간 정보 소실; (2) 수십억 파라미터 VLM을 통째로 파인튜닝 → 막대한 연산 비용. 논문의 질문: "대규모 비전 사전학습의 표현 이득을, 수십억 파라미터 생성 모델의 비용 없이 물려받을 수 있는가?"

2핵심 Contribution

  • Dense patch 토큰의 직접 활용 — 동결 ViT의 patch feature(예: 16×16×384)를 풀링 없이 정책에 공급, 조작에 필수적인 세밀한 공간 밀도를 보존.
  • Block-causal attention mask — 프레임 내부는 완전 양방향으로 patch들이 서로 참조, 프레임 간에는 causal 마스킹으로 시간 인과성 유지. 표준 정책의 시간 구조를 깨지 않으면서 관찰당 다수 patch 토큰에 attend.
  • 극한의 효율 — 동결 백본 + 작은 정책 트랜스포머만 학습. OpenVLA-OFT의 0.7% 파라미터, ~1/6 지연, 1×L40S 6.5 GPU-hour로 학습하면서 성능은 상회.

3Method

Observation Trunk (관찰 인코딩)

이미지 관찰 ot ∈ ℝC×H×W를 동결 ViT로 인코딩해 P×D 형태의 patch feature를 얻는다(P=patch 수, D=임베딩 차원). 길이 T의 컨텍스트 윈도우면 T×P×D 시퀀스가 된다. 목표 조건화는 이미지 기반(concat → T×P×2D)이나 벡터 기반(concat → T×P×(D+G)) 모두 지원. 멀티뷰(otview0, otview1)와 goal image/vector가 각각 ViT/Linear로 인코딩돼 하나의 토큰열 zt로 합쳐진다.

Block-Causal Attention (핵심)

feature를 T×P 길이 시퀀스로 펼치고 1D 위치 임베딩을 더한 뒤, block-causal mask를 적용:

  • 프레임 내부(intra-frame): 같은 프레임의 patch들끼리 완전 양방향 attention → 프레임 내 공간 정보 통합.
  • 프레임 간(inter-frame): causal 마스킹 — 현재/과거 프레임 patch만 참조, 미래 프레임은 차단 → 정책의 시간 인과성 보존.
직관: CLS 하나로 압축하면 공간이 사라지고, 전 프레임 full-attention이면 시간 인과성이 깨진다. block-causal은 "프레임 안에서는 이미지를 넓게 보되, 프레임 사이에서는 미래를 못 보게" 하는 절충으로 두 이점을 모두 취한다.

5Ablation (주요 발견)

  • 공간 밀도가 핵심(Table 4): 학습형 convolution으로 patch 해상도를 256→1로 압축하면 Push-T가 0.69→0.48로 급락. "원본 토큰의 세밀한 공간 밀도가 결정적"임을 확인.
  • attention mask(Table 12): block-causal이 full-attention·token-causal과 같거나 우위. full-attention은 태스크 인과성 위반, token-causal은 Diffusion Policy에 프레임 맥락이 불충분(Cube 0.11 vs 1.24).
  • 모델 크기(Table 13): VQ-BeT·Diffusion Policy 모두 용량에 따라 일관 향상. Push-T coverage 0.50(4층)→0.57(6층)→0.69(8층).
  • 인코더 선택(Figure 5): WebSSL·DINOv2가 최강, SigLIP 2는 약함 — 언어-이미지 정렬을 우선해 조작에 필요한 기하 특징이 부족하다는 가설.
