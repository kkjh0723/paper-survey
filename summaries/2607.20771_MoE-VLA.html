Emergent Compositional Skills in Mixture-of-Experts VLAs

Shlok Shah, Rhiaan Jhaveri, Tharun Kumar Tiruppali Kalidoss, Chirayu Nimonkar, Ishaan Javali · 2nd Workshop on Compositional Learning, ICML 2026

arXiv abstract PDF arXiv:2607.20771
VLA Mixture-of-Experts LoRA Compositional Interpretability

제출: 2026-07-22 · 백본 π₀ + SmolVLA · LIBERO-10 벤치 · LoRA rank r=16 · 라우팅 top-k

한 줄 요약 (TL;DR)

과제 계층을 명시적으로 정의하지 않아도, 단순화된 MoE action head를 가진 VLA는 재사용 가능한 해석 가능한 원시 스킬로 태스크를 자발적으로 분해한다. 액션 익스퍼트의 FFN을 LoRA(rank 16) 델타로 만든 MoE로 대체하고, 포워드당 1회 라우팅(모든 MoE FFN 레이어에 동일 가중치 적용)만으로 π₀·SmolVLA 백본을 위에 얹어 학습. LIBERO-10에서 dense baseline과 성능은 동일하되, Expert A/B/C 등이 "이동·놓기", "그리퍼 해제", "얇은 손잡이 접근"에 대응하도록 자연스레 나뉜다.

1배경 · 문제의식

기존 계층 조작(HRL·option framework·hierarchical VLA)은 사람이 스킬 라이브러리를 미리 설계해야 하고, 학습 후에도 스킬 경계가 모델과 일치하지 않는 경우가 많다. 저자들은 다음 질문을 던진다: "태스크 계층 없이 학습된 flat VLA에서, 단지 MoE 구조만 얹으면 스킬 분해가 emergent 하게 일어날까?" 답은 예: 라우터 하나가 태스크 초기 시각·언어·상태를 보고 하나의 익스퍼트를 선택하면, 각 익스퍼트가 재사용 가능한 원시 행동에 자발적으로 특화된다.

2핵심 Contribution

  • 단순화된 MoE Action Head — 액션 익스퍼트의 FFN sublayer만 MoE화, self-attention은 익스퍼트 공유. 각 익스퍼트는 LoRA(r=16) 델타로 표현 → 파라미터 절약 + 초기 재현성(0-init).
  • Global one-shot routing — 시각·언어·proprioceptive를 concat한 라우터 MLP가 포워드 1회만 top-k 선택 → 모든 MoE FFN 레이어에 동일 게이팅. Token/layer별 라우팅보다 일관된 end-to-end 행동을 만든다.
  • Emergent skills 발견 — 학습 후 익스퍼트가 (a) 전송/배치 phase, (b) 그리퍼 open&retract, (c) 가느다란 손잡이 접근·파지 같은 원시 행동에 특화되며, 특정 익스퍼트는 여러 태스크에서 35–45% 선택되는 재사용성.

3Method

LoRA-MoE FFN

액션 익스퍼트 트랜스포머의 각 FFN을 다음처럼 확장:

FFNMoE(x) = FFNbase(x) + Σe∈TopK we · ΔWe(x),
ΔWe는 rank r=16 LoRA, 초기 0이라 학습 초에는 dense baseline과 정확히 동일한 정책을 출력.

Self-attention은 전 익스퍼트 공유(=파라미터 증가 억제, 라우팅이 layer-wise가 아닌 스킬-wise가 되도록).

One-shot Global Routing

라우터 = 2-layer MLP. 입력은 비전 임베딩 + 언어 임베딩 + proprioceptive 상태의 concat. softmax(logits) → top-k 선택 → 재정규화된 가중치를 모든 MoE FFN 층에 동일하게 적용. 즉 라우팅 결정이 forward 전체에서 한 번만 일어남 → 익스퍼트가 coherent skill을 표현하게 강제.

학습 목적

기존 flow-matching 손실에 load-balancing 정규화(λLB=0.01)를 추가해 routing collapse(한 익스퍼트에만 몰림) 방지.

4실험 결과

정량: dense baseline 매칭

LIBERO-10에서 MoE 확장이 dense baseline과 동등한 성공률을 유지(작은 차이). 즉 MoE 구조가 성능 저하 없이 해석 가능성을 얻어낸다는 것이 정량 주장 — 이 워크숍 논문의 핵심 취지는 성능 SOTA가 아닌 emergent decomposition의 존재 증명.

정성: 익스퍼트별 특화 (그림 참조)

  • Expert A: 파지 후 최종 이송·배치 국면. 여러 태스크에서 반복 사용(재사용율 35–45%).
  • Expert B: 그리퍼 open + retract(놓기+빼기). 대부분 태스크의 종료 국면.
  • Expert C: 얇은 손잡이 물체 접근·파지(펜·플라이어). 특정 파지 스타일에 특화.
  • Task-specific: 1–2 태스크에만 집중되는 익스퍼트도 존재 → 재사용/전용 스킬이 자연 분리.

Expert 재사용 분석

여러 태스크에서 특정 익스퍼트가 동일 phase(예: 최종 배치)에 선택되는 빈도를 히트맵으로 표시. 이는 라우터가 태스크 라벨 없이도 phase-level 유사성을 학습했음을 시사.

5Ablation (주요 발견)

  • Global routing → Token/Layer 라우팅으로 바꾸면 익스퍼트가 뒤섞여 phase-level 해석 가능성 붕괴.
  • Self-attention도 MoE화: 학습 불안정 + emergent 스킬 분해 약화. FFN-only가 sweet spot.
  • Load balancing 제거: 특정 익스퍼트로 라우팅이 몰려 다양성/해석 가능성 하락.
  • Zero-init LoRA: 초기부터 dense와 동일 정책 → 성능 저하 없이 안전한 파인튜닝 워머업 가능.
  • 수동으로 "이 태스크는 Expert A" 강제해 보면 baseline 대비 유사하거나 살짝 낮음 → 학습된 라우터가 사람 라벨보다 자연스러운 분해를 찾음.
